# Sample Images Directory

This directory contains real-world road surface and pothole photos extracted from `archive/2023 pothole dataset/` for offline model evaluation and testing:

- `pothole_sample_1.jpg` (from `1.L.jpg`)
- `pothole_sample_10.jpg` (from `10.L.jpg`)
- `pothole_sample_50.jpg` (from `50.L.jpg`)
- `pothole_sample_100.jpg` (from `100.L.jpg`)
- `pothole_sample_200.jpg` (from `200.L.jpg`)

### Full Archive
The complete dataset containing **494 stereo road hazard photos** is located at `archive/2023 pothole dataset/`.
